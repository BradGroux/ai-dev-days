# AI Dev Days Context

This context defines event and curriculum terms that have specific meaning in
AI Dev Days materials.

The
[AI-Native Operating Framework glossary](https://github.com/BradGroux/ai-native-operating-framework/blob/v1.0.0/framework/glossary.md)
governs framework terminology. Local terms below describe educational or
tool-specific implementation context and do not amend the framework.

## Language

**Agent Harness**:
A reusable work environment around an AI agent: source material, instructions,
memory, tools, loops, verification, and human approval points.
_Avoid_: Prompt trick, chatbot wrapper

**Tool Track**:
An event or curriculum path that uses a particular product or technical
environment to apply the program. A tool track is not a framework requirement.

**Research Disposition**:
An accountable decision to accept a note as bounded evidence, advance it to a
proposal, defer it, supersede it, or reject it. Publication alone is not a
disposition.

**Reviewable Artifact**:
An output whose sources, purpose, status, boundaries, checks, and responsible
reviewer are clear enough for another person to assess.

**Workshop Memory**:
The public-safe, durable context an attendee or facilitator keeps so work can
continue after an event. It may contribute to shared operating memory, but it
is authoritative only when its source, status, scope, and approval support that
use.
