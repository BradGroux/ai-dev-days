## I am adapting this repo for a new event

Copy the event template folder, give it a date-first name, then update the
audience-specific assumptions:

```bash
cp -R event-specific/_template event-specific/YYYY-MM-DD-<event-slug>
```

Before committing public-facing material, run:

```bash
./scripts/publication-scan.sh
node scripts/audit-repo.mjs
node scripts/check-external-links.mjs
```
