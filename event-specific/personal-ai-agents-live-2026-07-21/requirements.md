# Requirements

## Presenter

- OpenClaw available for the planning and PRD phase.
- Codex available for issue artifacts, `/goal` prompt generation, and app build.
- A clean local workspace with this event packet open.
- Browser available for the static app output.
- Source corpus and fallback artifacts opened before the session starts.
- Final `slides.html`, `slides.pdf`, and speaker notes available once presentation work is complete.

## Attendees

Attendees can follow along by watching the workflow.
They do not need to install OpenClaw or Codex during the live session.

## Source Material

- Use the live generated corpus slice if model/runtime conditions are good.
- Use [demo/source-corpus/](demo/source-corpus/) as the full fallback corpus.

## Safety Boundary

Do not paste secrets, API keys, tokens, credentials, real personal data, real customer records, live incident details, or non-public work material into the demo.
Do not connect live accounts, send external messages, create live GitHub issues, open pull requests, merge code, deploy code, delete data, or trigger irreversible actions.
