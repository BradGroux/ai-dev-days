# Facilitator Runbook

Use this as the live control panel for the Personal AI Agents LIVE workshop.

## Operating Goal

Show the complete workflow:

1. context
2. `$grill-with-docs`
3. PRD
4. issue artifacts
5. `/goal`
6. implementation plan
7. static app output

## Timing

| Time | Move |
|---:|---|
| 0-5 min | Frame OpenClaw vs. Codex responsibilities and safety boundary. |
| 5-10 min | Generate a small E Corp corpus slice live, or switch to fallback corpus. |
| 10-20 min | Run the OpenClaw `$grill-with-docs` PRD planning path. |
| 20-25 min | Review the generated PRD and name the app output. |
| 25-32 min | Move to Codex and generate issue artifacts plus `/goal` prompt. |
| 32-40 min | Start the app build from the goal or show prepared fallback. |
| 40-45 min | Open app or fallback output, show Build Trace, take questions. |

Use the slide deck as a pacing aid, not as the main artifact.
The live proof is the workflow and app output.

## Cut If Behind

Cut simulated commits and pull requests first.
Keep the PRD, issue artifacts, `/goal`, and Build Trace.

## Safety Boundary

Do not paste secrets, API keys, tokens, credentials, real personal data, real customer records, live incident details, or non-public work material into the demo.
Do not connect live accounts or take external actions.

## Close Line

The point is not that one model made an app.
The point is that the workflow preserved context, forced planning, created scoped work, and produced a reviewable local artifact.
