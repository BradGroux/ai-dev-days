## The promise

See what changes when the same tools inherit a defined way of working: purpose, owners,
requirements, procedures, evidence, and useful prior decisions. Leave with a small operating packet
you can use with a different tool tomorrow.

“Rent” means tools are replaceable choices, including tools you run yourself. Ownership here means
retaining access to, control of, and the ability to export your operating knowledge. It is not a
claim about a provider's legal terms or that every tool is subscription software.
