# Requirements

No installation, paid AI account, or coding experience is required to attend.
Bring a laptop only if you want to complete the optional worksheet digitally.
A paper worksheet is sufficient. The presenter supplies all demonstration tools.

Presenter requirements: working Codex, Buzz, Ollama with a downloaded local model,
Grok Build, OpenClaw, DeepSeek Harness preview, and a local Veritas Kanban board.
ChatGPT receives a brief orientation; Claude Code is explanation only.
See the [presenter runbook](facilitator-runbook.md) for isolation and rehearsal.

Do not put secrets, API keys, private data, sensitive personal notes, or anything
confidential in a public repository, shared file, screenshot, or projected prompt.
When in doubt, keep it local.
