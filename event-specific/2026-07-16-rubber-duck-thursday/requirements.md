# Session Requirements

## Presentation

- Use the local [slides.html](slides.html) as the primary presentation surface.
- Keep [slides.pdf](slides.pdf) open as the rendering fallback.
- Keep the PowerPoint copy available for upload or organizer handoff.
- Present at 16:9 and verify every slide at full size before the stream.
- Keep source links visible on slides 4, 5, 7, 8, and 10.

## Demo

- Open [demo/index.html](demo/index.html) locally.
- Use only the fictional checked-in scenario data.
- Keep agent output draft-only.
- Do not connect email, ERP, finance, CRM, LIMS, scheduling, inventory, or carrier accounts.
- Do not send messages, approve invoices, release lab results, reschedule crews, or change shipments.

## Safety

Do not put or paste secrets, API keys, tokens, credentials, private data, sensitive personal notes, real customer information, or anything confidential into projected prompts, public files, or screenshots.

## Technical

- A modern browser with local file access
- PDF viewer
- Stable stream connection for the YouTube event
- Optional second screen for notes and demo navigation
