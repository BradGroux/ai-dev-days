# SOP: Daily Field Dispatch Handoff

1. Read open work orders, priority, site access, permits, and skill requirements.
2. Read crew availability, qualifications, equipment, and current constraints.
3. Flag any job that cannot safely start.
4. Draft a proposed sequence with reasoning and open questions.
5. Run checks for skill coverage, equipment, access windows, and permits.
6. Present the draft to the dispatcher and safety owner.

Stop if a permit, certification, access window, equipment inspection, or emergency escalation path is missing. Do not assign crews, contact customers, or change the scheduling system.
