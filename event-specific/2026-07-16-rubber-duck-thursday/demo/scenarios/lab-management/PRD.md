# PRD: Lab Release Review Agent

## Problem

Lab managers need a complete evidence packet before they can release a result, but the evidence spans sample records, methods, controls, duplicates, calculations, and chain of custody.

## Goal

Assemble a draft release-review packet that exposes every QC or custody exception.

## Output

- sample status table
- QC and custody holds
- missing-evidence list
- reviewer questions
- release-approval checklist

## Boundaries

- No result changes
- No electronic signature
- No report release
- No regulated or personal data in the demo

## Acceptance Criteria

- Every sample links to method, QC, and custody evidence.
- QC failures and incomplete records are held.
- Release authority remains with the lab manager.
- All outputs are labeled draft-only.
