# Fallback Plan

## If the HTML Deck Fails

Open [slides.pdf](slides.pdf). The PDF contains the same 15-slide sequence and visible source links.

## If the Demo Lab Fails

Open [demo-script.md](demo-script.md) and walk the Accounts Payable example
from source notes to draft packet. The expected output is also checked in under
[demo/scenarios/accounts-payable/expected-output.md](demo/scenarios/accounts-payable/expected-output.md).

## If Time Is Cut

Use the short sequence in [agenda.md](agenda.md). Show one workflow only: Accounts Payable.

## If Connectivity Is Unreliable

Everything required for the talk works from local files. The only unavailable surfaces will be the event page and external source links.

## Safety Fallback

If any prompt, tab, or screenshot contains private data, stop screen sharing
and return to the checked-in fictional packet. Do not put secrets, API keys,
tokens, credentials, private customer data, or confidential material into the
public demo.
