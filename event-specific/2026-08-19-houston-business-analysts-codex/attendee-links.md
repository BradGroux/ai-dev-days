## What to reuse

- Copy the canvas and templates from the workbook for a small workflow.
- Compare the fictional source notes with the completed process brief.
- Use the example `AGENTS.md` for standing workspace rules and boundaries.
- Keep required rules in approved documentation; use memory only as helpful
  recall.
- Adapt the SOP, PRD, skill, and acceptance scenarios together so the sources,
  procedure, reusable workflow, and proof remain aligned.
- Practice the pattern with change-impact or prioritization evidence before
  introducing real organizational data.

## No installation required

This is a presenter-led Codex session. Bring questions and a generic workflow you would like to analyze. A laptop is optional.

Do not put secrets, API keys, private data, sensitive personal notes, real customer records, or anything confidential in public repositories, shared files, screenshots, or projected prompts.
