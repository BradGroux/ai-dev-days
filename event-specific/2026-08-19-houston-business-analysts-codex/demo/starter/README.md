# HOUBAs Live Discovery Workspace

This generated workspace contains only fictional Northstar Field Services
material. It exists so the live Codex demonstration starts with raw evidence
instead of exposing the completed fallback packet.

## Sequence

1. Open this folder as the Codex workspace.
2. Begin with `prompts/01-audit-current-state.md`.
3. Capture audience decisions in `drafts/audience-decisions.md`.
4. Continue with prompts 02–04 only as time and audience interest allow.
5. Use the checked-in `demo/workspace/` for the completed operating packet and
   vendor-review skill.

## Safety

Do not add real company, customer, vendor, credential, financial, or personal
data. This workspace is disposable. Preserve any wanted draft before running
the preparation command with `--reset`.
