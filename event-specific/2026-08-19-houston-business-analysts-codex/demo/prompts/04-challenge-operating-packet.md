# Prompt 04: Challenge the Operating Packet

```text
Goal:
Adversarially review drafts/operating-packet before anyone treats it as reusable.

Context:
Read AGENTS.md, framework-guidance.md, source/, drafts/current-state-audit.md,
drafts/process-brief.md, and every file under drafts/operating-packet/.

Framework stage:
This is Validate. Findings return to Document; only accountable humans can
Approve, and no external Use occurs here.

Check:
1. unsupported rules or invented authority,
2. missing owners or handoffs,
3. undefined or conflicting terms,
4. data without source, owner, validation, or missing-data behavior,
5. exceptions without escalation, stop, recovery, or evidence,
6. PRD requirements without acceptance scenarios,
7. scenarios without a governing requirement,
8. memory or framework guidance incorrectly promoted to policy, and
9. any step that creates, approves, changes, or communicates externally.

Constraints:
Use the six framework concerns and eight SOP content areas as completeness
checks, not as Northstar decision rules. Do not edit files during this review.

Done when:
Return findings in severity order with exact file and source references, the
responsible owner, and the smallest safe correction. State explicitly when no
finding exists in a checked area.
```
