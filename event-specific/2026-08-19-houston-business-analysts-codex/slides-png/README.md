# Individual 1080p Slide Images

This folder contains the 27 presentation slides as individually numbered PNG
files from `slide-01.png` through `slide-27.png`.

- Dimensions: 1920 x 1080 pixels
- Aspect ratio: 16:9
- Theme: dark
- Source: the 1920 x 1080 slide images embedded in [`../slides.pdf`](../slides.pdf)
- Ordering: zero-padded filenames preserve slide order in file browsers

The images were extracted losslessly from the published PDF rather than
recaptured or resized.
