# Reference Links

These are the public sources behind the Codex-specific claims and the event
links used in this packet. Product behavior can change, so re-check the
official documentation before the August 19, 2026 session.

## Codex foundations

- [Codex best practices](https://learn.chatgpt.com/guides/best-practices)
  - frames prompts around goal, context, constraints, and done-when evidence
  - describes `AGENTS.md` as durable repository guidance
  - explains that guidance closer to the working directory takes precedence
- [How Codex uses `AGENTS.md`](https://learn.chatgpt.com/docs/agent-configuration/agents-md)
  - official reference for repository and nested instruction files
- [Build skills](https://learn.chatgpt.com/docs/build-skills)
  - defines a skill as a reusable workflow with a required `SKILL.md`
  - documents repository-scoped skills under `.agents/skills`
  - explains explicit and implicit invocation and progressive disclosure
- [Memories](https://learn.chatgpt.com/docs/customization/memories)
  - explains local Codex memory behavior and controls
  - explicitly positions memory as helpful recall, not the only source for
    required team rules
- [Codex prompting](https://learn.chatgpt.com/docs/prompting)
  - official guidance for clear, scoped requests and verification
