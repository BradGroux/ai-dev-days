# Requirements

This is a virtual guest talk. Attendees do not need to install software or
create accounts.

## Presenter requirements

- Modern browser with the [HTML slide deck](slides.html) available locally
- Stable Internet connection
- Working camera and microphone
- Screen-sharing access
- Twelve 1920x1080 slide screenshots and the assembled PDF after slide approval
- Speaker notes available on a second screen or printed

## Organizer confirmation

- Meeting link and presenter access
- Recording consent and archive plan
- Final introduction and professional bio
- Organizer introduction and questions scheduled outside Brad's 20-minute talk

## Public-safety boundary

Use only public, fictional, or sanitized examples. Do not put secrets, API keys,
tokens, credentials, private data, client details, or sensitive personal
information in projected prompts, screenshots, shared files, or public
repositories.
