# Fallback Plan

Use this if display, network, model provider, OpenClaw, or Veritas Kanban fails.

## If The Display Fails

Use the 30-second hook verbally:

> OpenClaw is a personal AI assistant you run on your own devices. The Gateway is the control plane for durable context, tools, channels, nodes, and visible agent workflows.

Then show attendee links on your laptop or phone.

## If Slides Fail

Use [slides.pdf](slides.pdf). If both deck formats fail, use this talk track:

1. OpenClaw is not just another chat surface.
2. The Gateway connects clients, channels, nodes, tools, sessions, and memory.
3. Business value comes from bounded workflows: context, role, policy, artifact, verification.
4. Veritas Kanban shows the execution layer after an agent turns context into tasks.
5. Follow the docs or Discord for install and deeper help.

## If OpenClaw Fails

Do not troubleshoot live for more than 45 seconds. Say:

> The setup is not the point of the floor demo. The workflow pattern is the point.

Then walk through:

1. [demo/business-ops-memory.md](demo/business-ops-memory.md)
2. [demo/business-ops-prd.md](demo/business-ops-prd.md)
3. [demo/business-ops-sop.md](demo/business-ops-sop.md)
4. [prompt-pack.md](prompt-pack.md)
5. [demo/expected-output.md](demo/expected-output.md)

## If Veritas Kanban Fails

Treat Veritas as a talking point, not a live dependency:

- Tasks need owners, status, evidence, and review.
- Veritas Kanban is a local-first example of that execution layer.
- OpenClaw can help produce the task map, but a human still decides what becomes work.

## If Network Fails

- Use local slides.
- Use local demo files.
- Use [demo/expected-output.md](demo/expected-output.md).
- Offer the repo and Discord verbally.

## If The Attendee Wants To Use Private Data

Say:

> Do not paste private company data into a floor demo. Describe the shape of the workflow, and we will use synthetic placeholders.

Then replace details with:

- "Customer A"
- "Internal system"
- "Contract term"
- "Approval owner"
- "Deadline"

## If Time Is Cut To 60 Seconds

Use this:

> OpenClaw turns AI from a one-off chat prompt into a local-first assistant workflow:
> durable context, bounded tools, channels, nodes, memory, and visible review.
> For business use, the first safe win is not letting agents do everything.
> It is turning messy context into a draft plan, task map, risk list, and human approval checkpoint.
