# Speaker Notes - Conference Floor Version

These notes support the [slides.html](slides.html) deck. Use them in short pieces. Floor conversations should be interactive, not a formal talk.

## Slide 1: OpenClaw At The Open Source Zone

Core point: this is a maintainer conversation, not a sales pitch.

Say:

> If you work with AI agents, the hard part is not getting one response. The hard part is context, tools, safety, and follow-through.

## Slide 2: The Fast Hook

Use when someone is walking by.

Say:

> OpenClaw is a personal AI assistant you run on your own devices. The Gateway is the control plane for durable context, bounded tools, channels, nodes, and visible workflows.

## Slide 3: Why Business Users Should Care

Core point: business value comes from repeatable workflows.

Say:

> Most companies do not need more generic text. They need intake, decisions, tasks, approval, and evidence.

## Slide 4: The Mental Model

Keep it simple:

- clients and channels bring work in
- Gateway routes it
- runtime assembles context
- tools and nodes act
- sessions and memory preserve the trail

## Slide 5: The Workflow Pattern

Use the five words:

> Context, role, boundary, artifact, verification.

This is the floor-safe pattern. It works even if the live demo fails.

## Slide 6: Business Demo

Do not say "watch the AI run a business." Say:

> Watch how a messy intake becomes a draft operating packet and task map.

## Slide 7: Maintainer Demo

Tie it to GitHub:

> Maintainer work is also operations: classify, prioritize, ask for missing info, and decide what should happen next.

## Slide 8: Veritas Kanban

Use Veritas as a concrete adjacent example.

Say:

> Veritas started as a way to manage OpenClaw work. Now it shows the next step: agent output becomes trackable work with owners, states, review, and evidence.

## Slide 9: Safety Model

Do not overpromise.

Say:

> Local-first is a strong starting point, but production use still needs identity, policy, approval, audit, and careful data boundaries.

## Slide 10: Conversation Routes

Ask one question:

> What workflow would you want an agent to help with if it had the right context?

Then route to business, maintainer, architecture, install, or Veritas.

## Slide 11: Build Week Follow-Up

Point people to After Hours if relevant. Keep exact times tied to current event pages if anyone asks.

## Slide 12: Links

End with:

> Start with docs and a safe draft-only workflow. Do not begin by connecting every channel or automating external actions.
