# Requirements

This floor packet assumes maintainers are staffing a booth or shared Open Source Zone space. Attendees do not need to install OpenClaw during the conversation.

## Maintainer Machine

- Laptop with local admin access.
- Power adapter and display adapter.
- Local copy of [slides.html](slides.html).
- Final [slides.pdf](slides.pdf) export regenerated after slide approval.
- OpenClaw installed and already onboarded if running the live demo.
- Model provider configured and tested before arriving.
- Clean demo workspace with no private files.
- Demo files from [demo/](demo/) opened locally.
- Browser tabs limited to public-safe docs, GitHub repos, and local files.
- Do Not Disturb enabled.

## Optional Demo Software

- OpenClaw dashboard available locally.
- A terminal session in the clean demo workspace.
- Optional Veritas Kanban local instance or screenshots if Brad chooses to show the execution layer live.
- Local copy of [docs/openclaw-architecture.md](../../docs/openclaw-architecture.md).

## Network Fallback

- Slides available offline.
- Demo expected output available in [demo/expected-output.md](demo/expected-output.md).
- Hotspot available if venue Wi-Fi is unreliable.
- Printed or locally cached attendee links if QR scanning fails.

## Public Safety

Do not paste secrets, API keys, tokens, credentials, private attendee information, private DMs, sponsor terms, customer records, unreleased announcements, private repo data, or internal company details into the demo.

Do not connect live messaging accounts, send external messages, publish content, merge PRs, delete data, rotate credentials, or trigger irreversible actions from the floor demo.

Use synthetic or public-safe examples only. Keep generated outputs draft-only until reviewed by a human.
