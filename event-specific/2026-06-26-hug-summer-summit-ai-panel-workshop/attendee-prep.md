# Attendee Prep

You can attend the H.U.G. AI panel without installing anything. If you want to
participate in the hands-on workshop, do the optional prep below.

## Before The Session

1. Bookmark the event start page: [attendee-links.md](attendee-links.md).
2. Review [requirements.md](requirements.md).
3. Pick one low-risk workflow where AI could help.
4. Gather public or sanitized source material only.
5. Decide which model provider you can use if installing OpenClaw.
6. Decide where the reviewed output would live: Discord, Teams, WhatsApp,
   Telegram, Signal, email, or an internal document.

## Good First Workflows

- Summarizing public reading-support research.
- Drafting volunteer orientation material.
- Creating a tutoring activity checklist.
- Turning meeting notes into action items.
- Drafting a grant-support outline from public program descriptions.
- Creating a parent or community-partner FAQ draft for human review.

## Poor First Workflows

- Anything involving private student data.
- Donor records or private financial information.
- Staff records.
- Private meeting links or attendee lists.
- Credentials, API keys, passwords, or tokens.
- Externally sent messages without review.

## Safety Reminder

Do not paste secrets, API keys, tokens, credentials, private student data,
donor data, staff records, confidential notes, or anything sensitive into
public tools or shared workshop material.
