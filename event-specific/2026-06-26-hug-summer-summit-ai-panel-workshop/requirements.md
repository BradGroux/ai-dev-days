# Requirements

This session has two modes: listening during the panel and hands-on work during
the interactive workshop.

## Required For Everyone

- Modern browser
- Reliable internet connection
- Notebook or notes app
- A low-risk workflow idea you would be comfortable discussing publicly

## Required For Hands-On OpenClaw Setup

- Mac or Windows laptop
- Ability to install software
- Terminal, PowerShell, or Windows Terminal
- Git: <https://git-scm.com/>
- Node.js LTS: <https://nodejs.org/>
- Optional editor: VS Code <https://code.visualstudio.com/>
- Optional notes app: Obsidian <https://obsidian.md/>
- A model provider account, key, or workshop-provided provider details

No Discord, Teams, WhatsApp, Telegram, or Signal account is required for the
hands-on setup. Channels are discussed as workflow entry points, not configured
live.

## OpenClaw Baseline

1. Install OpenClaw for your operating system.
2. Run OpenClaw onboarding.
3. Choose a model provider.
4. Verify the gateway.
5. Open the dashboard.
6. Get one model response.
7. Create one memory file and one `AGENTS.md` instruction file.
8. Identify one channel where the reviewed output would be useful.

## Safety

Do not put secrets, API keys, tokens, credentials, private student data,
donor data, staff records, confidential notes, or anything sensitive into
chat, GitHub, screenshots, shared files, or projected prompts.
