## Workshop Flow

1. Understand AI in plain English.
2. See the difference between chatbots and agentic AI.
3. Learn what OpenClaw adds: memory, instructions, tools, and visible loops.
4. Install OpenClaw.
5. Configure a model provider.
6. Create a small reading-support research agent.
