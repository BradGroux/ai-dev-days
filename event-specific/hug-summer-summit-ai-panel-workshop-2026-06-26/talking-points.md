# Talking Points

Use these as modular lines for the panel, not a script.

## One-Liner

AI gets useful when people stop treating it like magic and start putting a
harness around it: context, memory, instructions, tools, review, and human
judgment.

Process beats model choice: the source material, boundary, review step, and
next decision matter more than which model or wrapper runs the task.

## What Is AI?

- AI is software using data to make predictions or generate useful output.
- Generative AI creates new text, images, code, plans, summaries, and drafts.
- The output can sound confident even when it is wrong.
- Human judgment and source checking matter more, not less.

## What Is Agentic AI?

- A chatbot answers a prompt.
- An agent works toward a goal.
- An agentic workflow includes context, memory, tools, steps, review, and stop conditions.
- The best first agent work is draft-only and human-reviewed.

## What Is OpenClaw?

- OpenClaw is a local-first control plane for agent workflows.
- It connects model providers, memory, instructions, tools, sessions, channels, and automations.
- Memory and `AGENTS.md` make context explicit instead of hidden in chat history.
- OpenClaw is the workbench. The workflow still needs human ownership.
- Channels such as Discord, Teams, WhatsApp, Telegram, and Signal are entry
  points into the same bounded workflow, not permission to skip review.

## Education And Workforce Readiness

- The durable skill is AI workflow literacy.
- Students should learn how to ask good questions, provide context, check sources, and review outputs.
- Educators can use AI to reduce prep friction while keeping instruction human-led.
- Nonprofits can start with research summaries, volunteer guides, checklists, and drafts.

## Responsible AI

- Start with allowed data and forbidden data.
- Define what the agent may draft and what it may never do.
- Require human approval before sharing, posting, sending, or changing records.
- Verify sources before acting.

## H.U.G. Use Case

The safe first workflow is a reading-support research agent:

1. public or sanitized sources,
2. a memory file,
3. an `AGENTS.md` role and boundary file,
4. a draft brief,
5. a skeptical review,
6. a human approval point.

## Do Not Say

- "AI can replace teachers."
- "Just paste your student data here."
- "The agent can make the decision for you."
- "No review needed."
- "This is fully autonomous."
