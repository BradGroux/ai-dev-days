## Purpose

The session should make AI feel practical, not magical. The useful takeaway is
that AI agents work best when people give them clear context, safe boundaries,
good source material, repeatable loops, and review gates.

OpenClaw is the concrete example: a local-first way to give agents memory,
instructions, tools, model-provider access, and visible work.

## Core Message

AI is not the strategy. The strategy is building a harness around AI so useful
work can happen safely:

1. give it real context,
2. keep sensitive data out,
3. define the job,
4. run a visible loop,
5. verify before acting,
6. keep humans in charge.

## Demo Outcome

The simplest hands-on path is a reading-support research agent:

1. install OpenClaw,
2. choose a model provider,
3. create a local workspace,
4. add a small memory file and `AGENTS.md`,
5. ask the agent to turn public reading-support notes into a reviewed brief,
6. run a skeptical review before using the result.

## Safety Boundary

Do not put secrets, API keys, tokens, credentials, private student data,
donor data, staff records, confidential notes, or anything sensitive into
public repositories, projected prompts, screenshots, or shared files.

Use public, fictional, or sanitized examples. Treat AI output as a draft until
a human reviews it.
