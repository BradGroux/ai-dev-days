# SOP: Business Operating Packet Demo

## Purpose

Provide a safe repeatable method for turning synthetic business notes into a draft operating packet and task map during a conference-floor demo.

## Required Inputs

- Demo memory
- Demo PRD
- Sample public-safe business notes
- Attendee clarifying answers, if provided

## Steps

1. Read the memory, PRD, SOP, and source notes.
2. Ask clarifying questions before drafting.
3. Produce the smallest useful operating packet.
4. Convert the packet into Veritas-ready task cards.
5. Run a safety and approval review.
6. Mark all outputs draft-only.

## Safety Boundary

Do not use:

- secrets
- API keys
- tokens
- credentials
- private DMs
- attendee contact data
- customer records
- employee records
- sponsor terms
- contracts
- unreleased announcements
- private operational details

Do not:

- send messages
- publish content
- create live external tasks
- merge code
- delete data
- rotate credentials
- trigger irreversible actions

## Review Checklist

Before using any output, a human must verify:

- facts
- links
- owner names
- dates
- customer or employee references
- approval requirements
- security assumptions
- whether any task should exist in a live tracker

## Stop Conditions

Stop and ask for human review if the workflow requires private data, live credentials, legal commitments, regulated records, external sends, production access, or irreversible actions.
