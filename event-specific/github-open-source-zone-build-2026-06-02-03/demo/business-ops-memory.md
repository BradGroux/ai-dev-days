# Business Ops Demo Memory

## Goal

Show how OpenClaw can turn messy business context into a draft operating packet and Veritas-ready task map.

## Audience

Microsoft Build attendees who care about business workflows, engineering operations, product delivery, open source maintainership, or AI agent adoption.

## Workflow Pattern

1. Context
2. Role
3. Boundary
4. Artifact
5. Verification

## Source Notes

Use [sample-public-business-notes.md](sample-public-business-notes.md).

## Desired Output

- operating packet
- decision list
- risk list
- approval gates
- Veritas-ready task cards
- verification checklist

## Data Boundary

Use synthetic and public-safe notes only.

Do not use secrets, API keys, tokens, credentials, private DMs, attendee contact data, customer records, employee records, sponsor terms, contracts, unreleased announcements, or private operational details.

## Positioning

OpenClaw makes the workflow visible. Veritas Kanban is the example execution layer where the resulting work can become trackable tasks.
