# Sample Public Notes

Use these notes for the live demo. They are intentionally generic and public-safe.

## Event context

- Event: GitHub Build creator pre-day OpenClaw demo.
- Venue: GitHub HQ, San Francisco.
- Audience: technical creators, builders, and operators.
- Talk length: 10 to 15 minutes.

## Core message

OpenClaw makes the agent workflow visible:

- context that survives beyond one prompt
- controlled access to files and tools
- connectivity across clients, channels, nodes, and automations
- verification before anything gets published or shipped

## Useful examples

- turn a conference note into a recap post
- turn a technical demo into a 3-minute video outline
- turn public event notes into a follow-up checklist
- keep private DMs, sponsor details, and unreleased announcements out of drafts

## Desired tone

Practical, technical, direct, and not hype-heavy.
