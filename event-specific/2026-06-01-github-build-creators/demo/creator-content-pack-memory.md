# Creator Content Pack Memory

## Goal

Turn public-safe Microsoft Build week notes into a small creator content pack.

## Audience

Technical creators, builders, and operators who care about practical AI workflows.

## Source Notes

Use [`sample-public-notes.md`](sample-public-notes.md) as the source material.

## Data Boundary

Use public-safe notes only.

Do not use private DMs, sponsor terms, attendee contact data, unreleased announcements, credentials, customer records, private customer information, or private operational details.

## Desired Output

- a short recap post
- a 3-minute video segment outline
- a verification checklist
- a follow-up path to the SSTB Discord

## Review Standard

The content must be accurate, source-grounded, practical, and reviewed by a human before publishing.
