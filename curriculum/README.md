# AI Dev Days Curriculum

This folder contains the reusable teaching path for AI Dev Days.

The
[AI-Native Operating Framework](../docs/ai-native-operating-framework-alignment.md)
is the operating foundation. The curriculum applies it through practical
events, tool tracks, reviewable work, and public learning.

The
[AI Dev Days research and education method](../docs/research-and-education-method.md)
governs how source findings become learning objectives, how curriculum is
validated and approved, and how event evidence is dispositioned.

The curriculum is built around a simple progression:

1. Define the purpose, owner, expected outcome, and boundaries.
2. Create durable context from identifiable sources.
3. Give people and AI clear roles, authority, and handoffs.
4. Perform one useful activity with a selected tool.
5. Test the output against explicit completion criteria.
6. Preserve evidence, work state, handoff, and lessons.
7. Improve the activity from outcomes and feedback.

This progression is also mapped to the U.S. Department of Labor's AI Literacy
Framework: understand AI principles, explore AI uses directly, direct AI
effectively, evaluate AI outputs, and use AI responsibly. The delivery model
emphasizes hands-on learning, context, human judgment, prerequisites, continued
learning, enabling roles, and agility.

## Facilitator Stance

Protect the first useful, reviewable operating loop. Deeper material is
valuable only after attendees understand the purpose and human owner, can use
the selected tool with durable context, and can verify an output. In an
OpenClaw track, a successful OpenClaw response is the tool checkpoint rather
than the full program outcome.

Treat learners as sources of context and evidence, not passive recipients.
Separate what occurred in one event from an approved reusable curriculum
change.
