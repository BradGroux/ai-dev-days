# AI Literacy Framework Alignment

OpenClaw Dev Days is aligned to the U.S. Department of Labor's AI Literacy
Framework so facilitators can explain the workshop as workforce AI literacy,
not just tool training.

Source: U.S. Department of Labor, Employment and Training Administration,
[AI Literacy Framework / TEN 07-25](https://www.dol.gov/sites/dolgov/files/ETA/advisories/TEN/2025/TEN%2007-25/TEN%2007-25%20%28complete%20document%29.pdf),
released February 13, 2026. The DOL news release describes the framework as
guidance for AI literacy efforts across workforce and education systems and
notes that it outlines five foundational content areas and seven delivery
principles: [ETA news release 26-199-NAT](https://www.dol.gov/newsroom/releases/eta/eta20260213).
The graphic version shared by DOL is here:
[AI Literacy Framework graphic](https://www.dol.gov/sites/dolgov/files/OPA/newsreleases/2026/02/ETA-20260212-hi.jpg).

## Foundational Content Areas

| DOL content area | OpenClaw Dev Days treatment |
| --- | --- |
| Understand AI Principles | Orientation explains agents, models, context, memory, limits, and why AI output needs human review. |
| Explore AI Uses Directly | Attendees use OpenClaw on their own goal and the Beaver Badges product scenario instead of only watching demos. |
| Direct AI Effectively | Markdown memory, agent roles, prompts, task lists, and output contracts teach attendees how to give clear context and instructions. |
| Evaluate AI Outputs | Contract checks, reviewer rubrics, repair loops, and human orchestration make evaluation a first-class skill. |
| Use AI Responsibly | Publication safety, least-privilege roles, credential handling, and public-safe examples keep responsibility visible throughout the workshop. |

## Effective Delivery Principles

| DOL delivery principle | OpenClaw Dev Days treatment |
| --- | --- |
| Enable Experiential Learning | Every major block ends with an artifact: first response, memory note, agent role, contract, review, repair plan, or 30-day goal. |
| Embed Learning in Context | Exercises use attendee projects, local workspace files, event scenarios, and the Beaver Badges sample product. |
| Build Complementary Human Skills | The curriculum repeatedly asks attendees to use judgment, scope decisions, communication, creativity, and domain knowledge. |
| Address Prerequisites to AI Literacy | Setup guides, helper lanes, rescue paths, and beginner-friendly Markdown scaffolds reduce access and skill barriers. |
| Create Pathways for Continued Learning | Handoff prompts, 30-day build goals, community links, and reusable agent-role files support next steps after the event. |
| Prepare Enabling Roles | Facilitator runbooks, helper lanes, reviewer roles, and train-the-trainer notes support people guiding other learners. |
| Design for Agility | Modules are Markdown-first, scenario-based, and easy to refresh as models, tools, policies, and workplace use cases change. |

## Facilitator Use

Use this alignment in proposals, sponsor conversations, workforce-development
framing, and facilitator prep. Do not turn it into a lecture. The point is to
make the workshop's practical exercises visibly map to a public workforce AI
literacy framework.

Recommended framing:

```text
Today is not a prompt-tricks class. We are practicing AI literacy as an operator skill: understanding what AI can and cannot do, exploring useful workplace use cases, directing tools with clear context, evaluating outputs, and using AI responsibly.
```

## Curriculum Implications

- Keep hands-on practice in every block.
- Keep evaluation and responsibility attached to real artifacts.
- Keep role boundaries and least-privilege thinking visible.
- Keep setup prerequisites humane, with helper lanes and rescue paths.
- Refresh examples frequently so the workshop stays current with AI capabilities and workplace use cases.
