## Runtime and maintenance scope

Beaver Badges is a small React browser app with static JSON, localStorage and
export; no production API, database, authentication, payments or server concurrency
exists. The Personal AI app is a fictional seeded local demo; interpolated values
are HTML-escaped and persistence is bounded to editable fields. The vendor CLI
uses fictional JSON, deterministic routing, local files and human approvals; it
has no external approval integration. Performance review found small bounded
fixtures rather than evidence supporting a caching/database architecture change.

Aggie authoring generates static HTML/PDFs and prepares new isolated directories;
existing destinations are refused and PDF regeneration has an explicit approval
gate. No deck layout or PDF regeneration is required for this edition. Existing
runtime/package/schema identities and event directory conventions stay intact.
The Aggie browser verification helper is macOS/Chrome-specific; it is a local
preflight, not a portable CI promise. PDF source hashes remain unchanged.

Security review covers publication hygiene, input/state validation, source trust,
provider data boundaries, permissions, local logging, dependencies, CI and release
identity. No confirmed private credential disclosure is reported. Regex/link gates
are limited checks, not evidence of absence of all vulnerabilities or correctness
of every external claim. Human/domain acceptance remains explicit.
